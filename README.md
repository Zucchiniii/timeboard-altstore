# Timeboard för AltStore

AltStore-källa för Timeboard: KronoX-schema, Blackboard och widgetar på iPhone (iOS 26+).

## Lägg till källan

Öppna på iPhonen:

**[Lägg till i AltStore](altstore://source?url=https://raw.githubusercontent.com/Zucchiniii/timeboard-altstore/main/source.json)**

eller lägg till den här adressen under *Källor* i AltStore:

```
https://raw.githubusercontent.com/Zucchiniii/timeboard-altstore/main/source.json
```

Har du redan installerat Timeboard från en IPA-fil räcker det att lägga till källan.
Nya versioner dyker sedan upp under *Mina appar* → *Uppdateringar*, och appen
uppdateras på plats med inställningar och inloggning kvar.
